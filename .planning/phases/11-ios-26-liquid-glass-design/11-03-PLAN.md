2. StatCard-Funktion anpassen -- bgColor wird als semi-transparenter Tint verwendet:
```tsx
function StatCard({ label, value, bgColor, accentColor }: StatCardProps) {
  // bgColor in rgba umwandeln fuer Glass-Tint
  // Die bgColor-Werte sind bereits helle Pastell-Farben (#EFF6FF etc.)
  // Wir nutzen sie als zusaetzlichen Overlay via style-borderColor
  return (
    <GlassCard style={[styles.card, { borderColor: accentColor + '40' }]} radius={12}>
      <Text style={[styles.cardValue, { color: accentColor }]}>{value}</Text>
      <Text style={styles.cardLabel}>{label}</Text>
    </GlassCard>
  );
}
```

Erklaerung: `accentColor + '40'` haengt hex-Alpha 40 (25% Opacity) an -- z.B. '#2563EB40'. Das gibt jeder StatCard eine subtile farbige Umrandung die die farbige Kategorisierung beibehalt ohne opake Hintergruende.

  padding: 16,
  // backgroundColor: entfernen (war: bgColor via prop)
  // shadowColor, shadowOffset, shadowOpacity, shadowRadius, elevation: entfernen (GlassCard hat eigene)
},

Glass-Effekte benoetigen Content HINTER der Blur-Schicht. Momentan ist der Hintergrund `colors.background` (#F9FAFB) -- ein neutrales Weiss. Um den Blur-Effekt sichtbar zu machen, ersetzen wir den ScrollView-Container durch einen LinearGradient-Hintergrund.

Lese alle drei Dateien. Dann fuer jeden Screen:

**Pattern (gleiches Vorgehen fuer alle drei Screens):**

1. LinearGradient importieren (falls noch nicht vorhanden):
```typescript
import LinearGradient from 'react-native-linear-gradient';
```

2. Den aeusseren ScrollView mit einem LinearGradient-Wrapper umgeben. Das Muster ist:
```tsx
// NEU: Gradient-Hintergrund umgibt den ScrollView
return (
  <LinearGradient
    colors={['#e8f7f4', '#edf5f9', '#f0f4f9']}
    start={{ x: 0, y: 0 }}
    end={{ x: 1, y: 1 }}
    style={styles.container}
  >
    <ScrollView
      style={styles.scrollView}
      contentContainerStyle={styles.content}
    >
      ...bestehender Inhalt unveraendert...
    </ScrollView>
  </LinearGradient>
);
```

3. Styles anpassen:
```typescript
// container (auf LinearGradient):
container: { flex: 1 },

// scrollView (neues Style statt altem container):
scrollView: { flex: 1, backgroundColor: 'transparent' },
```

Erklaerung der Gradient-Farben: `#e8f7f4` (leichtes Mint von gradientStart), `#edf5f9` (mittleres Blau-Mint), `#f0f4f9` (leichtes Blau von gradientEnd) -- sehr gedaempfte Varianten des App-Gradients. Auf diesem Hintergrund wirken Glass-Cards natuerlich.

Fuer DashboardScreen: Den obigen `<ScrollView style={styles.container} ...>` ersetzen. Der container-Style dort hat `backgroundColor: colors.background` -- das entfernen, container wird zu flex:1.

Fuer BadgeOverviewScreen: Gleiches Vorgehen. Auch hier `backgroundColor: colors.background` aus container entfernen.

Fuer HomeScreen: container hat `backgroundColor: colors.background` -- entfernen, LinearGradient uebernimmt.
