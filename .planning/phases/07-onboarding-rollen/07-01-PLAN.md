  <name>Task 2: authStore um onboardingCompleted erweitern + AppNavigator-Gate</name>
  <files>mobile/src/store/authStore.ts, mobile/src/navigation/AppNavigator.tsx</files>
  <action>
**authStore.ts — Erweiterung:**

1. `AsyncStorage` aus `@react-native-async-storage/async-storage` importieren (ist bereits im Projekt, wird in anderen Screens genutzt — nicht neu installieren)
2. `AuthStore` Interface erweitern:
```typescript
interface AuthStore {
  token: string | null;
  user: AuthUserState | null;
  onboardingCompleted: boolean;
  login: (token: string, user: AuthUserState) => void;
  logout: () => void;
  completeOnboarding: () => void;
  loadOnboardingState: () => Promise<void>;
}
```
3. Initial-State: `onboardingCompleted: false`
4. `completeOnboarding`: setzt `onboardingCompleted: true` im Store UND schreibt `AsyncStorage.setItem('onboarding_completed', 'true')` (fire-and-forget, kein await nötig im Action-Body — die Funktion selbst ist sync aus Store-Sicht)
5. `loadOnboardingState`: liest `AsyncStorage.getItem('onboarding_completed')` → wenn `=== 'true'` dann `set({ onboardingCompleted: true })`

**AppNavigator.tsx — Onboarding-Gate:**

1. `OnboardingScreen` importieren: `import OnboardingScreen from '../screens/onboarding/OnboardingScreen';`
2. In `AppNavigator`: onboardingCompleted aus Store lesen: `const onboardingCompleted = useAuthStore((s) => s.onboardingCompleted);`
3. `loadOnboardingState` aus Store holen: `const loadOnboardingState = useAuthStore((s) => s.loadOnboardingState);`
4. `useEffect(() => { loadOnboardingState(); }, [])` — lädt beim Mount den AsyncStorage-Wert
5. Navigations-Logik im Stack:
   - Wenn `token` vorhanden UND `!onboardingCompleted` UND `role === 'visitor'`: Zeige `OnboardingScreen`-Screen (nicht als Tab, als Stack.Screen)
   - Wenn `token` vorhanden UND (`onboardingCompleted` ODER `role !== 'visitor'`): Zeige `AuthenticatedStack`
   - Wenn kein `token`: Zeige Login/Register

Konkrete Implementierung in `AppNavigator`:
```typescript
// Im Stack.Navigator innerhalb von NavigationContainer:
{token ? (
  (!onboardingCompleted && role === 'visitor') ? (
    <Stack.Screen name="Onboarding">
      {() => (
        <OnboardingScreen
          onComplete={() => useAuthStore.getState().completeOnboarding()}
        />
      )}
    </Stack.Screen>
  ) : (
    <Stack.Screen name="App" options={{ headerShown: false }}>
      {() => <AuthenticatedStack role={role} />}
    </Stack.Screen>
  )
) : (
  <>
    <Stack.Screen name="Login" component={LoginScreen} />
    <Stack.Screen name="Register" component={RegisterScreen} />
  </>
)}
```

Hinweis: `useAuthStore.getState().completeOnboarding()` ist korrekt für den Aufruf außerhalb eines React-Contexts (in einer Callback-Prop). Alternativ kann man `completeOnboarding` via `useAuthStore` im AppNavigator holen und direkt übergeben.
