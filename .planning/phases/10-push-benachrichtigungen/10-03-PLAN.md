<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin -> POST /api/push/send | Nur Admin-Rolle -- Inhalte kommen vom Admin-User |
| Visitor -> PATCH /api/push/settings | Jeder eingeloggte User darf nur eigene Einstellungen aendern |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-09 | Elevation of Privilege | POST /api/push/send | mitigate | requireRole('admin') Middleware pflichtend -- Visitor kann keinen Massen-Push ausloesen |
| T-10-10 | Tampering | PATCH /api/push/settings fuer anderen User | mitigate | userId kommt aus req.user (JWT) -- kein userId-Parameter im Body erlaubt |
| T-10-11 | Tampering | Push-Text durch XSS/Injection | accept | Push-Text wird nicht in Browser gerendert, nur als native Notification angezeigt -- kein HTML-Rendering |
| T-10-12 | Spoofing | Fake-JWT fuer Admin-Push | mitigate | Bestehende authenticateToken Middleware validiert JWT-Signatur |
</threat_model>
