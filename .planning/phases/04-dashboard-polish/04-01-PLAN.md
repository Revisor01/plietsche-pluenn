  <behavior>
    - getDashboardStats(storeId, from, to) gibt zurück: { visits, itemsTaken, newItems, activeItems }
    - visits = COUNT(*) FROM checkins WHERE storeId=X AND createdAt BETWEEN from AND to
    - itemsTaken = COUNT(*) FROM items WHERE storeId=X AND status='taken' AND createdAt BETWEEN from AND to
    - newItems = COUNT(*) FROM items WHERE storeId=X AND createdAt BETWEEN from AND to (egal ob active oder taken)
    - activeItems = COUNT(*) FROM items WHERE storeId=X AND status='active' (KEIN Zeitraum-Filter — Gesamtstand)
    - Alle Zahlen als number (nicht string), 0 als Fallback
    - KEIN userId in Rückgabe — aggregiert, kein Personen-Tracking
  </behavior>
  <action>
    Erstelle `backend/src/modules/dashboard/dashboard.repository.ts`.

    Importiere: `db` aus `../../db/client`, `checkins`, `items` aus `../../db/schema`, `eq`, `and`, `gte`, `lte`, `count`, `sql` aus `drizzle-orm`.

    Exportiere eine Funktion `getDashboardStats(storeId: string, from: Date, to: Date)` die fünf separate Drizzle-Queries ausführt (oder mit Promise.all parallelisiert):

    1. visits: `db.select({ value: count() }).from(checkins).where(and(eq(checkins.storeId, storeId), gte(checkins.createdAt, from), lte(checkins.createdAt, to)))` → `result[0]?.value ?? 0`

    2. itemsTaken: analog mit `items`-Tabelle, zusätzliche Bedingung `eq(items.status, 'taken')`

    3. newItems: analog mit `items`-Tabelle, ohne Status-Filter (alle in Zeitraum angelegten Items)

    4. activeItems: `db.select({ value: count() }).from(items).where(eq(items.storeId, storeId), eq(items.status, 'active'))` — KEIN Datums-Filter (Gesamtstand)

    Rückgabetyp:
    ```typescript
    export interface DashboardStats {
      visits: number;
      itemsTaken: number;
      newItems: number;
      activeItems: number;
    }
    ```

    Promise.all für alle vier Queries gleichzeitig, dann Werte zusammenbauen.

    ```typescript
    export const statsQuerySchema = z.object({
      from: z.string().datetime({ offset: true }).transform(s => new Date(s)),
      to:   z.string().datetime({ offset: true }).transform(s => new Date(s)),
    });
    ```
    Falls `from` > `to`: throw Error mit statusCode 400 und message "from muss vor to liegen".

    **dashboard.router.ts:**

    ```typescript
    import { Router } from 'express';
    import { requireAuth, requireRole } from '../../middleware/auth';
    import { statsQuerySchema, fetchStats } from './dashboard.service';

    const router = Router();

    router.get('/stats',
      requireAuth,
      requireRole(['admin', 'volunteer']),
      async (req, res) => {
        const { from, to } = statsQuerySchema.parse(req.query);
        const storeId = req.user!.storeId;
        const stats = await fetchStats(storeId, from, to);
        res.json(stats);
      }
    );

    export default router;
    ```

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
